GamingOverlay 1.0.8

- Changed the overlay UI font to Segoe UI for a cleaner native Windows look.
- Added widget edit mode: press F10, drag/resize widgets, then close settings to lock the overlay again.
- Improved click-through behavior so the overlay does not block normal desktop/game input outside edit mode.
- Reworked FPS tracking to use the overlay render loop frametime instead of a synthetic fallback.
- Frametime graphs and 1%/0.1% lows now keep real render-loop samples even when PresentMon CSV data is unavailable.
- Installer, launcher update metadata, and GitHub release assets now point to v1.0.8.
